# 上线微信小游戏要做的事（个人身份）

整理：2026-11-06，根据网上第三方资料，**不是微信官方说明**。规则会变，真正办的时候以微信公众平台后台和官方文档为准，Claude 陪着一步一步来。

| 步骤 | 谁做 | 大概多久 | 说明 |
|---|---|---|---|
| 1. 注册小游戏账号 | 发起人 | 半小时 | 在微信公众平台（mp.weixin.qq.com）用一个没注册过的邮箱注册「小程序」，类目选游戏。个人身份要实名，用微信扫码确认。 |
| 2. 备案 | 发起人 | 几天到两周 | 2023 年 9 月起小程序都要备案。个人可以办，要身份证和手机号。 |
| 3. 软著（软件著作权登记） | 发起人办，Claude 准备材料 | 官方要排队，大约一两个月；也有更快的电子版权认证或代办 | 每款游戏一个。要游戏名、代码节选、使用说明，这些 Claude 可以生成。 |
| 4. 上传游戏包 | 发起人在 Mac 上 | 十几分钟 | 用微信官方的「微信开发者工具」打开 Claude 做好的游戏包，点上传。 |
| 5. 提交审核 | 发起人 | 几天 | 填游戏介绍、上传截图（Claude 准备）。 |
| 6. 开通广告（流量主） | 发起人 | 累计约 1000 人玩过以后 | 后台「推广」→「流量主」。门槛是老资料里的说法，要核实。 |

不能做的：游戏里卖东西（需要版号，个人拿不到，见决策记录 D-001）。

安全：AppSecret、上传密钥这类东西只放在发起人自己的电脑和微信后台，绝不发进仓库（仓库是公开的）。

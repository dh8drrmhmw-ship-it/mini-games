# 点球大战：会记仇的门将（暂名）

第二款游戏（决策记录 D-010）。状态：**原型**（2026-11-07）。

## 玩法（2026-11-08 改成闯关）

- **闯关**：十关，一关一个门将。每关进 5 个球就过关，有 3 次机会（被扑出、踢偏、打中门柱弹出去都少一次）。
  - 闯到哪一关，下次就从哪一关接着打；没过就再来这一关，不会回到第一关。
  - 过关按剩下的机会给星星（剩 3 次三颗星）；过了的关可以回去刷星星。
  - 每过一关解锁一个球员或一双球鞋；称号按过了几关给（替补 → 主力 → 点球手 → 球星 → 传奇 → 球王）。
- **两种操作**（2026-11-08 加进阶操作，D-015）：关卡页右上角可以切换。
  - 2026-11-08 发起人试了进阶操作：难度反而更低，也不想按住射门键，就要「划得越快力量越大」。**默认改回划一下（简单操作）**，进阶操作留在设置里（D-016）。
  - **进阶操作（可选，像实况）**：一只手在屏幕上拖动瞄准（左右、高低），球前面一条带子只画出球刚飞出去的一段（前两关还会画落点）；另一只手按住「射门」蓄力，松手；蓄力条过了白线就是蓄过头，球会往上飞；松手时往旁边一滑是弧线球；按下射门后罚球的人开始助跑，助跑时还能改方向，但改得越多越容易偏。
  - **门将在助跑时会先动**：爱晃的门将常常提前扑向一边（看见了就踢另一边）；会骗人的门将会先往一边晃一步，球踢出去时再扑另一边；等球的门将不动。
  - **简单操作（默认）**：往想踢的位置划一下（下面这些说明是简单操作的）。
- **射门（简单操作）**：往想踢的位置划。手指从球出发划到球门里哪一点，球就飞向哪一点；没划到球门线的高度是贴地球。
  - **弧线球**：球一开始沿着你最开始划的方向飞，最后拐到你松手的位置。弯得越大，门将越难调整，但也越容易偏。
  - **顺脚和反脚的弧线**：右脚顺的弧线是「先往右、再拐回左」，左脚反过来；反方向的弧线（外脚背）只能弯一点，还更容易偏。
  - **力量**：看这一划最快的时候有多快（2026-11-08 改：以前只看松手前那一下，画弧线时手指最后慢下来，球就变得很慢）。越快球越快，也越容易偏。踢出去显示球速。
  - **换脚**：右下角的按钮可以换左右脚。用逆足（不是惯用脚）力量、准头、弧线都打折，逆足星数越高打折越少。
  - 屏幕下方能看到罚球的脚和球鞋，踢的时候腿会摆过去。
  - 划的时候：只有第 1 关画出整条路线和落点（练习）；从第 2 关起什么都不画，只看得到手指划过的线和力量条（2026-11-08 再改）。
  - **门将会看你划手指**（2026-11-08 加）：站着等球的门将从你开始划就在看方向，划得越久（越犹豫），他越早看出来、越早动。要果断。
  - **越往死角越难踢准**（2026-11-08 加，同日又加大）：离中间越远、越高，偏差越大；大力踢死角最容易偏出。
  - **风**（2026-11-08 加）：第 4、6、8、9、10 关有风，左上角有风向标。球飞得越久被吹得越偏，要自己顶着风瞄（预览不算风）。

## 门将（十关）

门将有两种扑法（2026-11-08 加「等球」）：
- **猜**：射门前就猜好扑哪边（会晃、会做假动作），猜错方向就只能看着。
- **等球**：不猜，站着看清球的方向再扑。中路的、慢的、不够偏的球都会被扑出；只有又快又贴边的死角，或者一开始方向骗人的弧线球才进得去。等球的时候他几乎不晃，可以看出来。
后面的门将等球的次数越来越多，所以光靠「猜反方向」过不了关，得踢得又快又准。

## 手感、压力、奖励、惊喜（奶茶调配的教训，D-011）

- **手感**：踢球声（踢得越用力越响）、进网声、观众欢呼和叹气、门柱的「当」、裁判哨（声音由程序合成，不用素材）；进球时网会鼓起来、画面震一下、观众跳起来；差一点就扑到的球放慢镜头；安卓手机会震动（苹果手机的浏览器不支持震动，微信版可以）。
- **压力**：每关只有 3 次机会；门将一关比一关强。
- **奖励**：过关的星星、每关解锁的球员和球鞋、称号；帽子戏法和绝招有专门的庆祝；没过关时告诉你「骗过门将几次、被猜中几次、你最爱踢哪里」。
- **惊喜**：每关一个新门将（出场卡片写着身高、身材、特点）；门将的台词和假动作；球员的绝招。

## 广告位

- 一关没过时：「再给一次机会」（看广告，多 1 次机会，每次闯关一次）。
- 选球员、选球鞋时：没解锁的「试用一关」（看广告）。

## 长期留住玩家（2026-11-08）

更多点子见 `docs/点球大战-点子.md`。

现在的样子留不住人：十关打完就没东西了；没有每天回来的理由；也没法和别人比。小游戏能留住人，靠的大多是两样：每天有新东西、能和朋友比。能不能留住，最后要看真人数据（上了微信看「第二天还有多少人回来」）。

- **A（推荐）每日挑战 + 无尽模式 + 好友排行**：每天一个特别的门将和条件（大风、只能用逆足……），所有人同一题；无尽模式比谁连进得多；上了微信以后加好友排行和分享（「我把门神打穿了」）。做得快，正好是「每天回来」和「和朋友比」。
- **B 球员养成**：训练升级能力、收集更多球员和球鞋。长期目标多、广告位多，但容易变成数值游戏（发起人说过 FM 太数据化）。
- **C 和朋友对战**：你当门将设好扑救习惯，朋友来踢，互相挑战。最有新意，但要服务器，工作量最大，适合上微信以后再做。

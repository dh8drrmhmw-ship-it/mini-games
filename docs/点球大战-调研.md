# 点球大战：怎么更难、更好玩、更能留住人（调研和建议）

整理：2026-11-08。发起人试玩后觉得还是有点简单，要 Claude 自己去找类似的游戏和视频，想办法提高难度、让玩法更好、更能吸引人。发起人也会去玩实况足球（网游）的点球和任意球，录视频发来。

说明：云端的网络限制，打不开大部分攻略网站和视频网站，下面主要来自搜索结果的摘要，加上 Claude 自己的分析。发起人在实况足球里的录屏会比这些更直观。

## 别的游戏怎么做（看到的要点）

| 游戏 | 怎么踢 | 难在哪 / 好玩在哪 |
|---|---|---|
| 实况足球（eFootball） | 点球：左摇杆瞄方向，按射门键蓄力（力量条）；守门员也用摇杆选扑的方向 | 力量大了会飞，小了会被扑；两边都在猜 |
| FC（原 FIFA） | 点球：瞄准 + 「镇定圈」：球周围一个圈一缩一放，圈最小时射门最准；圈缩放的速度看球员的镇定能力 | 不光是瞄，还要抓时机；心理素质好的球员更好踢 |
| Flick Kick Football（手机） | 手指扫过球：方向、弧线、力量都由这一扫决定，要绕过人墙 | 人墙逼你踢弧线 |
| Football Strike（手机，Miniclip） | 任意球；生涯模式是一张一关一关的地图；可以和别人实时对战，轮流当射手和门将；可以打扮球员 | 对战让人一直玩；但有抽奖、机器人对手，评价两极 |
| 指尖点球（手机） | 滑动定方向和角度，要打中球门里的靶子；有任意球、倒计时模式 | 打靶给了明确目标 |

真实点球的研究（论文用了近 8000 个点球）：
- 门将「晚一点扑」（看清了再动）其实更好，但真实门将大多提前猜。我们已经做了「等球」的门将。
- 射手也可以「等门将先动」：助跑时看门将往哪边倒，再踢另一边。真实比赛里这招很常见，我们还没有。

## 我们现在为什么还是简单

1. 射门这一下没有「手上功夫」：划对了就进，没有时机、没有手抖。
2. 门将能猜、能等，但射手没法和门将「斗」：射手不能先看门将动。
3. 只有点球一种，十关都在做同一件事，打熟了就简单。

## 建议加的玩法（按先后）

**A. 点球的手上功夫（推荐先做）**
- **心跳圈**：手指按住时球周围有个圈一缩一放，松手时圈越小越准。紧张的时候（只剩最后一次机会、后面的关、观众起哄）圈跳得更快；球员多一项「心态」能力，心态好的圈跳得慢。像 FC 的镇定圈，但用我们自己的样子和名字。
- **助跑等门将**：按住球不放就是慢慢助跑。会猜的门将会在某个时刻先倒向一边，看准了再往另一边划就能骗过他；但等太久，助跑停住、力量变小，门将也可能根本不动（等球的门将）。这就是真实比赛里「后发制人」的斗法。
- 这两样一起，点球就从「瞄准」变成「瞄准 + 时机 + 斗心眼」。

**B. 任意球关卡**
- 关卡里点球和任意球交替；任意球有人墙（会跳）、不同距离和角度。
- 弧线绕过人墙；划到最后往下勾一下是下坠球；画法不同还能踢出飘的球。
- 人墙逼你一定要踢弧线，和现在的画弧线正好接上。

**C. 当门将**
- 换过来：你当门将，划手指扑救，对面的电脑射手也会记你的习惯（你老往左扑，他就往右踢）。
- 以后和朋友对战（轮流当射手和门将）就是在这个基础上做的。

**D. 留人的东西**（见 `docs/点球大战.md`「长期留住玩家」）：每日挑战、无尽模式、好友排行和分享。

## 学别人可以，照搬不行

- 瞄准圈、力量条、人墙、打靶、轮流当射手和门将，这些是这类游戏都在用的玩法，我们可以学（D-002）。
- 不照搬别人的画面、名字、关卡和代码，也不做换皮：一是规矩，二是照搬了也比不过原版。
- 我们自己的特色是「会记仇、有脾气的门将」，新玩法都要围着它来，比如：助跑时门将会骂你「快踢啊」，会记住你爱等多久再踢。

## 发起人的实况足球（手游）录屏（2026-11-08）

两段录屏（点球、任意球，都没声音）。Claude 逐帧看到的：

**点球**
- 镜头在罚球的人身后偏一侧，像电视转播；门将在远处，能看到他的站位和动作。
- 瞄准：球前面一支绿色箭头指向球门，手指拖动改方向，箭头长短表示力量和高度。
- 罚球的人助跑的时候，箭头还在，**助跑途中还能改方向**：门将先动，你就能改去另一边。
- 踢完有回放镜头。

**任意球**
- 练习模式可以自己摆球：俯视球场，手指拖到哪球就放在哪，再确认。
- 瞄准：屏幕左边一块「触摸板」，滑动控制方向和角度（高低）；球上方一条半透明的轨迹带，**只画出球刚飞出去的一段**，看不到落点。
- 球脚下有一根力量条（绿 → 橙 → 红），按住蓄力，松手的时机决定力量。
- 人墙五个人，门将站在人墙另一侧；旁边还有双方球员。
- 按钮：换罚球的人、挪位置、换镜头。

## 要不要做成「实况足球的手感」？

- **可以学的是操作手感**：先瞄方向和高度 → 再蓄力（时机）→ 助跑途中还能改方向、加弧线。这比现在「一划就完事」多了时机和临场反应，更难、更有「手上功夫」，实况玩家一上手就熟悉。
- **学不来、也不该学的是画面**：实况是大公司的真 3D、真球员、动作捕捉；微信小游戏首包只有几 MB，我们也没有 3D 动作素材，做不出那个画面。照着它的界面一模一样画也不行（D-002）。我们的样子、名字、门将要是自己的。
- **会不会吸引实况玩家**：会有一部分。熟悉的操作降低门槛，「一分钟一局、随手打开」是实况给不了的；但实况玩家不会因为我们像实况就离开实况。我们要靠实况没有的东西留住他们：会记仇、有脾气的门将，每天的挑战，和朋友比。
- 结论：**操作向实况靠（做成「进阶操作」），画面和玩法特色走自己的路。**现在的「一划射门」留着当「简单操作」，玩家在设置里选。

## 「高级版」的路线（建议）

1. **进阶操作 + 点球改造**：拖动瞄准（方向、高度，只显示开头一段轨迹）→ 按住蓄力条、松手定力量（太满会飞）→ 助跑途中可以改方向、画弧线；门将会提前动（真动或假动），你可以看准了再改。镜头可以换成转播式的侧后方。
2. **任意球**：20～30 米、不同角度；五人人墙会起跳；门将根据人墙站位；弧线、下坠、电梯球；关卡里点球和任意球交替；练习场可以自己摆球。
3. **留人**：每日挑战、无尽模式、好友排行、和朋友轮流当射手和门将。

## 发起人第二次反馈：照实况的任意球操作做（2026-11-09）

发起人：「往下勾」难懂，实况里没有；左边滑动调镜头方向，和落点有关；右手滑球、滑弧线，弧线大小也看球员能力；滑得慢，球就慢、踢得低。

Claude 重新逐帧看了发起人的实况任意球录屏（只能看录屏和文字攻略，网上的视频打不开）：
- 教学写着「在左侧滑动可控制方向与角度」；左边一个白框是触摸区，手指在里面拖，镜头跟着转。
- 球前面一根**黄箭头**指着球飞出去的方向；球上方一条半透明的绿色轨迹带，只画开头一段，带子会跟着弧线弯。
- 球脚下有力量条（绿 → 橙 → 红）。
- 按钮：定位球员设定、位置移动、切换视图。

文字攻略里的要点（多数是主机版和别的手机足球游戏，手机实况的细节没找到官方说明）：
- 力量决定高低：力量太大球会飞，太小过不了人墙；近距离直接打门大约六到七成半力量，越远要的力量越大。
- 弧线：先把方向瞄到人墙外面或门柱外面，再用弧线拐回来。
- 手机足球游戏常见做法：划得越快力量越大，划出弯就是弧线（EA 的手机足球游戏说明）。

据此改成：左手转方向（黄箭头），右手划一下，快慢定力量和高低，弯定弧线；见决策记录 D-018。

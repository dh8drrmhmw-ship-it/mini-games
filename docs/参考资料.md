# 参考资料

用到任何第三方代码、素材、数据前，先在这里登记许可证，确认允许商用。
「状态」：参考 = 只看思路；使用 = 代码、素材或数据进入项目；待确认 = 许可证还没核实。

## 开发工具（只在开发时用，不随游戏发布）

| 工具 | 用途 | 许可证 | 状态 |
|---|---|---|---|
| [TypeScript](https://github.com/microsoft/TypeScript) 6.0 | 编程语言、类型检查 | Apache 2.0 | 使用 |
| [Vite](https://github.com/vitejs/vite) 8 | 打包 | MIT | 使用（打包结果只含我们自己的代码） |
| [Vitest](https://github.com/vitest-dev/vitest) 5 | 自动测试 | MIT | 使用 |
| [ESLint](https://github.com/eslint/eslint) 10、[typescript-eslint](https://github.com/typescript-eslint/typescript-eslint)、@eslint/js、globals | 代码检查 | MIT | 使用 |
| @types/node | Node 的类型说明 | MIT | 使用 |
| GitHub Actions：checkout、setup-node、upload-pages-artifact、deploy-pages | 自动检查和部署 | MIT | 使用 |
| Playwright + Chromium（云端环境自带） | 在云端用浏览器打开测试页检查 | Apache 2.0 / BSD | 使用（不进仓库） |

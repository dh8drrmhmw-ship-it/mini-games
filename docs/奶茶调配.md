# 奶茶调配（暂名）

第一款游戏（决策记录 D-008）。状态：**原型**（2026-11-06）。

## 玩法

- 柜台前站着顾客，每人点一杯分层奶茶。杯子里的虚线框就是顾客要的样子：从下往上，按顺序装。
- 下面的瓶子里装着分层的配料。先点一个瓶子，再点杯子，最上面那一段配料就倒进去；只有正好是下一层要的才倒得进去。
- 瓶子之间也能倒：只能倒进空瓶，或者倒在同样的配料上面，能倒多少倒多少。用来把挡路的配料挪开。
- 杯子装满，顾客说「好喝！」离开，排队的下一位上来。右上角能看到下一位要什么。所有顾客都满意就过关，这时瓶子正好全空。
- 8 种配料：珍珠、牛奶、红茶、抹茶、芒果、草莓、芋泥、椰果。每种除了颜色还有花纹，颜色相近的也分得清。

## 关卡

- 100 关，提前生成好（`src/games/milk-tea/levels.json`），每个人玩到的第 N 关都一样。改了生成规则要运行 `npm run levels`。
- 每关都由电脑先解一遍，保证有解（自动测试每次都检查全部 100 关）。
- 难度用「最少要在瓶子之间倒几次」衡量：第 1 关 0 次（只教倒进杯子），第 2～3 关 1～3 次，往后逐渐到 6～10 次。
- 柜台前只站一位顾客时最难（只能按顺序做）；每逢 5 的倍数的关有两位顾客，可以挑着做，让人喘口气。
- 先要用的配料会故意多压在瓶底，逼玩家先把上面的挪开。
- 第 1～4 关和第 10 关有一句提示。

## 卡住时（广告位）

- **撤回**：每关免费 5 次，用完后看一段广告再给 5 次。
- **加空瓶**：看一段广告，多一个空瓶，每关最多一次。
- **走不通了**：电脑每走一步就检查一次「还能不能过关」。确定走不通时，马上告诉玩家，给出撤回、加空瓶（广告）、重来三个选择，不让玩家在死局里白费力气。
- 测试版没有真广告：弹出一个说明框，等 3 秒点「看完了」就算看完。

## 这次请发起人看什么（原型试玩）

1. 规则看一眼能不能懂？第 1～3 关有没有卡住不知道该干嘛的时候。
2. 前 10 关玩下来，想不想接着玩？有没有哪关觉得太难或太简单。
3. 「走不通了」这个提示是帮了忙，还是让人觉得被剧透？
4. 发给两三个朋友玩，不催，看有没有人自己又打开玩第二次（D-006 的判断标准）。

## 已知的不足（以后打磨时做）

- 没有声音和震动。
- 配料倒过去是一个圆球飞过去，还没有「倒」的动作。
- 有的关第一步就可能走进死局（比如第 9 关），要看试玩反馈再决定要不要放宽。
- 还没做微信版的平台层、分享、好友排行。

## 试玩反馈

- 2026-11-07，发起人：**有点无聊，缺少趣味性。**

Claude 的判断（为什么无聊，下一款要避开）：

1. **没有手感**：没有声音、没有真的倒的动作、没有震动，做对了也没有「爽」的一下。
2. **没有压力**：顾客永远等着，不会输，只是在做题。
3. **没有奖励**：过关后什么都没得到，第 30 关和第 3 关看起来差不多，不知道为什么要接着玩。
4. **没有惊喜**：100 关都是同一件事，没有新东西出现。

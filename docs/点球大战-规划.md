# 点球大战：整体规划（2026-11-09）

发起人：「手指划太快还是容易高，弧线不明显，门将不够强、很多简单的球扑不到；门将也要有属性；留人的玩法还没做。把整体规划深入想好发给我，不要再连续返工了。需要什么参考都想全。」

**一句话**：先把「手感地基」一次打牢（真实的球路、讲道理的门将、你能自己调的手感面板），再加玩法，最后做微信版。每一步动手前先说好「怎样算好」，做完先用电脑按这个标准测一遍，再给你链接。

---

## 一、为什么老是返工

1. **手感的数字是我猜的**。球速、高度、弧线这些数字，我是用「电脑模拟的玩家」测的，可真人的手指划多快，我一直不知道。每次你一试，和我猜的不一样，就得重来。
2. **球路和门将是一堆凑出来的公式**，不是照真实的道理算的。所以改一处、别处就坏：
   - 弧线加大了，门将被骗得更厉害；
   - 高度调缓了，人墙又太好过。
3. **没有先说好「怎样算好」**。比如「简单的球」到底多简单就该被扑出，从来没定过数，只能一遍遍调。

## 二、以后怎么做才不返工

1. **先定「手感目标表」**（第六节）：慢划、中划、快划分别该怎样；什么样的球门将必须扑出、什么样的球才进得去。你确认了，我照着做、照着测。
2. **做一个「调手感面板」给你用**：在手机上点开，几个滑块（力量灵敏度、弧线大小、门将强弱……），你一边踢一边拖，觉得对了点「复制手感码」发给我，我把它定成正式的。你的感觉直接说了算，不用再隔着录屏来回猜。
3. **记录你真实的划法**：调试模式下，每一脚踢完在角落显示这一划的快慢、弯度，最近 20 脚可以复制成一串码发给我。我按你真实的手来定数字。
4. **球路换成真实的物理**：重力、空气阻力、旋转带来的拐弯和下坠（叫「马格努斯效应」），数字用论文里实测的值。弧线、下坠是自己算出来的，不是硬凑，改一处不会牵动别处。
5. **门将换成「来得及就扑得到」**：看他反应多快、扑得多快、手能伸多远，算他能不能在球到之前够到球。「简单的球」自然就扑得到；门将属性也直接对上这几项。
6. **每次交给你之前，先自动跑一遍「标准测试」**：慢、中、快 × 直、弯，各踢几十脚，对照目标表。不达标不给你。
7. **一次只改一件事**，改完就问你一两个具体问题，比如「门将扑中路慢球，你觉得够稳吗」，而不是问「好不好玩」。

## 三、要你拍板的 4 件事

**1. 任意球的高低怎么控制？**
- **A（推荐）左手管方向和高低，右手管力量和弧线。**
  - 左手左右拖是转方向，上下拖是抬高、压低（黄箭头跟着变陡、变平）。
  - 右手划得快慢，主要决定球速；对高低只有一点影响。
  - 这正是实况教学里写的「在左侧滑动可控制方向与角度」。也能解决「划快了就高」：高低是你用左手定的，不会因为手快就飞。
- B 维持现在：高低全看右手划多快。
- C 和点球一样：右手划到哪，球就往哪飞。

**2. 球路怎么算？**
- **A（推荐）换成真实物理。**
  - 弧线能拐 2～4 米（看球员弧线能力），和真实任意球差不多，看得出来。
  - 下坠、电梯球都能自然做出来。
- B 继续调现在的公式（容易继续返工）。

**3. 门将怎么做？**
- **A（推荐）换成「来得及就扑得到」，再加五项属性**（第七节）。
  - 简单的球一定扑得到，只有又快又贴死角的球才进得去。
  - 十个门将的强弱一眼能看出来。
- B 只在现在的基础上再加强一些。

**4. 先做什么？**
- **A（推荐）先打牢手感地基**（第五节阶段 1，大约一周），再做新玩法。
- B 先加新玩法，手感以后再调（玩法做得越多，以后改手感牵连越多）。

## 四、游戏最后长什么样

- **闯关**：十关、十个门将，点球加任意球。门将有属性、有脾气、会记仇。
- **当门将**：换你来扑，电脑射手也会记你的习惯。
- **点球大战**：五轮，你踢一个、扑一个，打平进突然死亡。
- **每天回来**：每日挑战（大家同一题，看排名）、每日任务、门将来复仇。
- **收集**：门将图鉴（打败的收进来，还有稀有怪门将）、进球集锦（精彩进球的慢镜头回放）、解锁球员和球鞋（不卖东西）。
- **和人比（微信版）**：好友排行、挑战好友、群排行。
- **赚钱**：只靠「玩家自己想看」的激励视频（再给一次机会、试用球员）。

## 五、分阶段计划

每一步都会给你测试链接，并告诉你这一步要看什么、怎样算过关。

### 阶段 1：手感地基（约 1 周）

| 步 | 做什么 | 给你看什么 | 怎样算过关 |
|---|---|---|---|
| 1.1 | 调手感面板 + 记录真实划法 | 面板能打开、能拖、能复制手感码 | 你能自己调，码能发给我 |
| 1.2 | 真实物理的球路（任意球和点球都用）；弧线更明显：拖尾更长，弧线球有慢镜头 | 弧线、下坠、球速 | 弧线一眼看得出来；划快不会无故飞高 |
| 1.3 | 新门将：「来得及就扑得到」+ 五项属性；出场卡片和关卡页显示属性条；扑救动作分抱住、扑出、托出横梁、飞身扑救 | 十个门将的扑救 | 第六节门将那几条都达标 |
| 1.4 | 任意球操作定稿（按你在第三节选的） | 左手方向、高低，右手力量、弧线 | 你觉得像实况 |
| 1.5 | 你用面板调到满意 → 我定成正式数字，重新调十关难度 | 定稿版 | 你满意；普通玩家第 3 关能过（看朋友试玩） |

### 阶段 2：玩法更丰富（约 1 周）

| 步 | 做什么 |
|---|---|
| 2.1 | **当门将**：电脑射手踢，你往一边划就扑；射手各有脾气（爱勺子、爱大力、助跑停顿），也会记你爱往哪扑 |
| 2.2 | **点球大战**：五轮轮流踢和扑，突然死亡；赢了有奖杯 |
| 2.3 | **任意球的花样**：球员绝招扩到任意球。比如电梯球（不转的大力球，飘着往下掉）、落叶球（往下坠）、外脚背弧线；人墙起跳时，贴地球能从脚下钻过去，后面的门将会放一个人躺在人墙后面防这招 |
| 2.4 | **门将的招**：每个门将一个专属本事（读心大师看得穿弧线、跳跳弹得特别高、话痨假动作……），和属性对上 |
| 2.5 | **打靶、打横梁挑战**：限时打中球门里的靶子，以后当每日挑战用 |

### 阶段 3：每天回来的理由（约 4 天）

| 步 | 做什么 |
|---|---|
| 3.1 | **每日挑战**：每天一题（比如「大风 + 只能用逆足」），3 次机会，先在本机记录，微信版接好友排名 |
| 3.2 | **每日任务**：每天 3 个（「用左脚进 3 个」「绕过人墙进 2 个」），完成给图鉴卡、称号、外观 |
| 3.3 | **门将来复仇**：输给你的门将第二天带新招回来；赢了他，台词会变 |
| 3.4 | **门将图鉴 + 稀有门将**（外星门将、机器人门将、村口大爷，各有怪招）+ 成就 |
| 3.5 | **进球集锦**：精彩进球自动存下，侧面角度慢镜头回放，微信版可以分享 |

### 阶段 4：微信版（约 1 周）

| 步 | 做什么 |
|---|---|
| 4.1 | 平台层换成微信的：画面、两指触摸、存档、声音、震动 |
| 4.2 | 激励视频广告：看完才给奖励；广告没加载好不显示按钮；每天次数有限，要先检查 |
| 4.3 | 分享：分享卡片和图片；好友排行用微信的「开放数据域」单独画 |
| 4.4 | 健康游戏忠告、隐私保护说明；首包大小检查 |
| 4.5 | 打包；写给你的上传步骤（Mac 上微信开发者工具）；审核用的截图和介绍 |

过关标准：你用手机扫码，在微信里能完整玩一遍，广告和分享都正常。

### 阶段 5：上线以后

- 先发给朋友和群，看三个数：第二天还有多少人回来、每人玩多久、看广告的次数。
- 按数据决定先加强哪一块。

## 六、手感目标表（草案，请你确认或改）

**任意球（正面 20 米，球员能力中等）**

| 怎么踢 | 应该怎样 |
|---|---|
| 慢慢划 | 球速约 60 公里/时，软绵绵：打人墙，或者被门将轻松抱住 |
| 中等速度划，角度合适 | 约 80～90 公里/时，越过人墙落进门里；门将扑得到的位置就会被扑出 |
| 很快地划，角度合适 | 约 100～110 公里/时，球更平更快；不会因为手快就飞上看台，最多刚好高出横梁 |
| 划一个明显的弯 | 球拐 2～4 米（弧线能力 1 拐 2 米左右，5 拐 4 米左右），看得出来 |

**门将（以中间几关的门将为准）**

| 什么样的球 | 应该怎样 |
|---|---|
| 踢到门将身边 1.5 米以内 | 几乎都扑出（九成以上） |
| 慢球（1.2 秒以上才到门） | 不贴死角就扑出（八成以上） |
| 又快又贴死角（离门柱半米以内、上角或下角） | 好门将也只扑出三到五成；最后一关门神可以到六成 |
| 越过人墙、贴近角 | 门将被人墙挡住视线、动得晚，最难扑 |

**点球**

| 什么样的球 | 应该怎样 |
|---|---|
| 中路、慢 | 站着等球的门将几乎都扑出；猜了一边的门将会扑空 |
| 死角、大力 | 进球的机会大，但容易偏出 |
| 弧线 | 只拐一点（点球离得近） |

## 七、门将属性（草案）

五项，每项 1～5 格，出场卡片和关卡页都显示：

| 属性 | 意思 | 管什么 |
|---|---|---|
| 反应 | 球踢出去多快开始动 | 越高越早扑 |
| 速度 | 扑出去有多快 | 越高越能扑到远处的球 |
| 臂展 | 身高加弹跳，手能伸多远、多高 | 越高越够得到死角、上角 |
| 预判 | 猜得准不准、会不会被弧线骗 | 越高越难骗 |
| 稳定 | 扑到以后抱得住还是脱手 | 越低越容易扑到了却没挡住 |

另外还有「脾气」（猜还是等、爱不爱晃、会不会假动作、会不会记仇），这个不算格子，写在卡片上。

## 十、参考了什么、还要借鉴什么

**已经查过的**
- **真实球路**：
  - 足球空气动力学的研究：Goff 和 Carré 的测量，Physics Today《Power and spin in the beautiful game》；Bray 和 Kerwin 从真实任意球录像算出的数。
  - 要点：踢得好的任意球全程在「阻力小」的状态；阻力系数约 0.25～0.3，旋转带来的升力系数约 0.23～0.29。
- **门将的研究**：门将大约只有半秒决定往哪扑，扑到一边平均要 0.6 秒左右；横向冲出去的速度最关键；训练好的门将能多覆盖约 42 厘米。用来定门将属性对应的数字。
- **别的游戏怎么做**（只学玩法类型，不照搬名字、画面、代码，D-002）：
  - 实况足球：任意球左手调方向和角度、黄箭头、开头一段轨迹、力量条。
  - EA 的手机足球：划得越快越有力，划出弯是弧线。
  - Football Strike：五轮任意球轮流射和守的对战、往一边划就扑、射门时划得太直太快会飞过横梁。
  - Flick Kick：一划射门。
- **任意球攻略**：近距离要六到七成半力量，太大会飞；先把方向瞄到人墙外面，再用弧线拐回来。
- **微信官方文档**：
  - 激励视频：看完（isEnded）才给奖励；每人每天次数有限；按钮要等广告加载好再显示。
  - 好友排行：只能在「开放数据域」里读好友数据，画到共享画布上再显示。
  - 适配器（weapp-adapter）：官方说明只是参考实现，我们不用游戏引擎，自己写平台层更省包。
- **怎么调手感**：做调手感面板、一次只改一个数、问具体的问题。这是做游戏常用的办法。

**GitHub 上的情况**：没有找到许可证清楚、又值得照着学的任意球或点球游戏代码。
- 搜到的多是只能在线玩的小游戏（看不到源码，或者许可证不明）。
- 还有一个 three.js 的足球人工智能演示，和任意球关系不大。

球路物理就几条公式，我们自己写更合适：包小，也不用担心许可证。以后用到任何外部代码，都先登记到 `docs/参考资料.md`、确认许可证（GPL 只看思路）。

**还想要的参考（需要你帮忙）**
- 实况里任意球「左手上下拖」会不会改高低：能录一段只拖左手、看黄箭头怎么变的吗？用来确认第三节第 1 件事。
- 实况里门将扑任意球的几段录屏（扑出、托出横梁、没扑到）。用来做扑救动作。

## 十二、风险和应对

| 风险 | 应对 |
|---|---|
| 调到你满意了，普通玩家却觉得太难 | 难度分开调：前几关放松，后几关保持；朋友试玩卡在哪就松哪 |
| 两只手操作，有人不习惯 | 左手不拖也能踢：默认方向对着球门中间，默认角度合适 |
| 物理球路在差一点的手机上卡 | 一脚球只算一次（一两毫秒），不会卡；阶段 4 在真机上再测 |
| 做微信版时发现限制（包大小、广告规则） | 阶段 4 一开始先查清、先做最小的版本上传试一次 |
| 软著排队太久 | 尽早办；必要时用付费加急或电子版权认证 |
